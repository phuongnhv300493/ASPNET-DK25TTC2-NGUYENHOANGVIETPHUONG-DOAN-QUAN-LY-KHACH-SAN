# BÁO CÁO TIẾN ĐỘ ĐỒ ÁN - TUẦN 1

**Đề tài:** Xây dựng Website Quản lý khách sạn sử dụng ASP.NET MVC 5 và SQL Server

**Thời gian thực hiện:** 22/06/2026 - 28/06/2026

## Mục tiêu tuần
Nghiên cứu cơ sở lý thuyết, xác định phạm vi đề tài và chuẩn bị nền tảng phục vụ quá trình phân tích, thiết kế hệ thống.

## Nội dung công việc
- Xác định lý do chọn đề tài, mục tiêu nghiên cứu, đối tượng nghiên cứu và phạm vi thực hiện.
- Tìm hiểu tổng quan về kiến trúc ASP.NET MVC 5 và mô hình Model - View - Controller.
- Nghiên cứu giao thức HTTP và quy trình trao đổi dữ liệu giữa Client và Server.
- Tìm hiểu các công nghệ hỗ trợ phát triển giao diện gồm HTML, CSS, JavaScript.
- Nghiên cứu thư viện jQuery và Bootstrap để xây dựng giao diện responsive.
- Chuẩn bị môi trường phát triển gồm Visual Studio, SQL Server và .NET Framework.

## Tài liệu liên quan
- Giáo trình phát triển ứng dụng Web với ASP.NET MVC.
- Khóa học lập trình ASP.NET MVC của TEDU.
- Mã nguồn giao diện Bootstrap SB Admin 2.
- Tài liệu Microsoft về ASP.NET MVC 5.

## Khó khăn gặp phải
- Cần hệ thống hóa lại kiến thức về mô hình MVC để áp dụng đúng vào thực tế.
- Tìm hiểu cách tích hợp các thư viện Front-end sao cho tối ưu.
- Chuẩn bị môi trường cài đặt .NET Framework và các công cụ phát triển phù hợp.
