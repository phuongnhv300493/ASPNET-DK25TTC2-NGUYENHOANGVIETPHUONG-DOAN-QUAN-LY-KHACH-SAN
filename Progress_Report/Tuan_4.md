# BÁO CÁO TIẾN ĐỘ ĐỒ ÁN - TUẦN 4

**Đề tài:** Xây dựng Website Quản lý khách sạn sử dụng ASP.NET MVC 5 và SQL Server

**Thời gian thực hiện:** 13/07/2026 - 19/07/2026

## Mục tiêu tuần
Hoàn thiện các chức năng quản trị và bổ sung tính năng mở rộng.

## Nội dung công việc
- Tích hợp giao diện quản trị SB Admin 2.
- Xây dựng chức năng CRUD cho:
  - Quản lý sản phẩm (Laptop).
  - Quản lý thể loại.
  - Quản lý đơn hàng.
  - Quản lý bài viết tin tức.
- Thiết lập giao diện quản lý vai trò và phân quyền.
- Tích hợp cơ chế phân quyền bằng ASP.NET Identity.

## Tài liệu liên quan
- ASP.NET Identity.
- Tài liệu phân quyền theo Roles (Admin/Khách hàng).
- Tài liệu SB Admin 2.

## Khó khăn khi viết thêm chức năng
- Gặp nhiều khó khăn khi tích hợp tính năng thông báo nổi khi có đơn hàng mới.
- Viết thuật toán gợi ý tự động kiểm tra thông tin khách hàng cũ để hỗ trợ tạo hồ sơ khách hàng mới tại trang quản trị.
- Quá trình thử nghiệm cấu hình Realtime mất nhiều thời gian và phát sinh nhiều lỗi cấu hình.

## Kết quả đạt được
- Hoàn thành toàn bộ màn hình CRUD của Admin.
- Phân quyền cơ bản hoạt động ổn định.
- Giao diện quản trị được tích hợp đồng bộ.

## Kế hoạch tuần tiếp theo
- Kiểm thử toàn bộ hệ thống.
- Sửa lỗi.
- Hoàn thiện báo cáo và slide bảo vệ.
